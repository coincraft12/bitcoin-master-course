# lesson-01 · 1-1 디지털 화폐의 난제: 이중지불과 신원 없는 합의

1부 기초 · 1강 비트코인 개요와 동작 원리

## 목표

- 이중지불 문제를 예를 들어 설명할 수 있다
- 중앙 기관 없는 합의가 왜 어려운지 말할 수 있다
- 비트코인 이전의 시도가 무엇을 풀지 못했는지 안다

## 실습

이 차시는 개념 차시로, 실습이 없습니다. 아래 질문에 자기 말로 답할 수 있으면 다음 차시로 넘어갑니다.

## 핵심 확인 질문

1. 이미지 파일은 복사하면 두 개가 됩니다. 1만 원짜리 "돈 파일"을 복사해 영희와 민수에게 거의 동시에 보내면 무슨 일이 생기나요? 이를 막으려면 무엇이 필요한가요?
2. 은행은 이중지불을 어떻게 막나요? 그 대가로 생기는 네 가지 위험(동결, 거부, 실수, 파산)은 무엇인가요?
3. 장부를 모두가 나눠 들면 "누구 장부가 맞는가"라는 문제가 생깁니다. 비잔틴 장군 문제(1982)와 시빌 공격(2002)은 각각 무엇을 말하나요?
4. DigiCash, Hashcash, b-money, Bit Gold, RPOW는 각각 무엇을 기여했고 무엇을 풀지 못했나요?
5. 비트코인은 투표권을 무엇에 묶었나요? 그것이 왜 시빌 공격을 무력화하나요? 장부가 갈라졌을 때는 어느 장부를 따르나요?

생각할 거리: 가짜 신원은 공짜로 만들 수 있지만 연산은 공짜로 만들 수 없습니다. 기술적 완성은 10-3(체인 선택)과 11-1(작업증명)에서 다룹니다.

## 흔한 오해 (1-1 MYTH VS FACT)

| 오해 | 사실 |
|---|---|
| 블록체인은 비트코인의 발명이다 | 해시로 기록을 잇는 타임스탬프 연구는 1990년대부터 있었다. 발명은 작업증명과 결합해 신원 없는 합의를 만든 조합에 있다 |
| 비트코인은 익명 화폐다 | 모든 거래가 공개되는 가명 시스템이다. 프라이버시는 14-3에서 다룬다 |
| 이중지불은 해킹 기술이다 | 디지털 화폐 설계가 기본으로 막아야 하는 구조적 문제다 |
