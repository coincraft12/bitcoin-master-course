# 13강 미니 과제: L2 비교표 1쪽 (13-4 · s13-assign)

13-4 체크리스트 6개 항목으로 **고른 L2 하나와 라이트닝을 나란히** 평가한다. 라이트닝 열은 슬라이드 예시로 채워 두었다. 고른 L2 열은 공식 문서와 현재 운영 상태로 채운다(답이 없으면 "문서에 없음").

## 파일
- `exercise_l2_compare.md` — 비교표 양식 (라이트닝 열 채움, 고른 L2 열 빈칸)
- `solution/l2_compare_example.md` — 작성 예시: Liquid(페더레이션 사이드체인)를 이 강의 슬라이드에 나온 사실만으로 채우고, 슬라이드에 없는 항목은 "공식 문서로 확인"으로 남긴 본보기

## 작성 요령
- 출처는 프로젝트의 **공식 문서**와 **공식 공지**만. 조사일을 적는다(운영 상태는 바뀐다 — Bitlayer BitVM Bridge는 2026년 5월 입금 중단, 6월 출금 창구 종료 뒤에도 웹 화면은 정상처럼 보였다는 보도가 있었다).
- 1번(출금 강제력)이 이번 강의 질문 그 자체다: "내 비트코인을 누구의 협력 없이 되찾을 수 있는가?"
- 두 열을 나란히 놓고 신뢰 가정 스펙트럼(단일 수탁 → 페더레이션 → BitVM 계열 → 라이트닝 → 온체인 직접 보관)에서 어디쯤인지 한 줄로 결론을 쓴다.

## 평가 포인트
- 6항목 모두 채웠는가 ("문서에 없음"도 답이다)
- 각 답에 근거(문서·절, 확인일)가 있는가
- 마케팅 문구와 문서 내용을 구분했는가
