# lesson-45 · 11-2 발행 스케줄과 반감기

## 목표
- 블록 높이로 블록 보조금을 계산한다.
- 최종 공급량이 2,100만 개보다 약간 적은 이유를 계산으로 보인다.
- 코인베이스 출력 ≤ 보조금 + 수수료와 그 검증 규칙을 설명한다.

```
보조금(sat) = (50 × 1억) >> (높이 ÷ 210,000의 몫)
```
오른쪽으로 한 칸 밀 때마다 절반, 정수 연산이라 sat 미만은 버려진다. 33번째 반감기(높이 6,930,000)부터 0, 2140년 무렵. 코드의 64는 C++에서 64 이상 시프트가 정의되지 않은 동작이라 넣은 안전장치(Core `GetBlockSubsidy`).
코인베이스 규칙: 출력 합계 ≤ 그 높이의 보조금 + 블록 내 수수료 합. 초과하면 블록 전체가 무효, 덜 청구하면 허용(영원히 사라짐). 코인베이스 출력은 100블록 뒤부터 쓸 수 있다.
