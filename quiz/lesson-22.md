# lesson-22 퀴즈 · 5-4 PSBT: 역할 분리, 워치온리·서명 지갑 실습, 5강 미니 과제

## Q1. 여러 서명자의 PSBT를 하나로 합치는 역할은?

- **A** Creator
- **B** Updater
- **C** Combiner
- **D** Extractor

<details><summary>정답</summary>

**C** — 각자 서명한 PSBT 병합

여러 서명자의 PSBT를 하나로 합치는 역할은 C, Combiner입니다. 각자 서명한 PSBT를 병합합니다. Creator는 빈 PSBT를 만들고, Updater는 정보를 붙이고, Extractor는 최종 트랜잭션을 꺼내는 역할입니다.

</details>

## Q2. 오프라인 서명기가 수수료를 검증하려면 무엇이 필요한가?

- **A** 받는 사람 이름
- **B** 입력이 쓰는 이전 출력의 금액
- **C** 블록 높이
- **D** 노드 IP

<details><summary>정답</summary>

**B** — 입력 합을 알아야 계산

오프라인 서명기가 수수료를 검증하려면 B, 입력이 쓰는 이전 출력의 금액이 필요합니다. 수수료는 입력 합 빼기 출력 합이므로 입력 쪽 금액을 알아야 계산됩니다. 블록 높이나 노드 IP는 수수료와 관계가 없습니다.

</details>

## Q3. 서명 전에 PSBT를 확인하는 가장 중요한 이유는?

- **A** 서명 속도 향상
- **B** 주소·금액·수수료 변조 확인
- **C** 블록 크기 확인
- **D** 노드 동기화

<details><summary>정답</summary>

**B** — 변조된 PSBT는 그대로 송금

서명 전에 PSBT를 확인하는 가장 중요한 이유는 B, 주소와 금액과 수수료의 변조 확인입니다. 감염된 온라인 기기가 변조한 PSBT에 서명하면 그대로 공격자에게 송금됩니다. 서명 속도나 노드 동기화와는 무관합니다.

</details>
