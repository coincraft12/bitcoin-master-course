## Q1. 2-of-3 멀티시그 복구에 키 2개 외에 꼭 필요한 것은?

- **A** 블록 높이
- **B** 모든 공개 디스크립터
- **C** 노드 IP
- **D** 수수료율

<details><summary>정답</summary>

**B** — 주소 재구성에 필요

2-of-3 멀티시그 복구에 키 2개 외에 꼭 필요한 것은 B, 모든 공개 디스크립터입니다. 주소를 재구성하려면 세 공개키가 모두 필요하기 때문입니다. 블록 높이나 노드 IP, 수수료율은 주소 재구성과 관계가 없습니다.

</details>

## Q2. 복구 지갑의 생성 시점을 적을 때 안전한 쪽은?

- **A** 조금 늦게
- **B** 조금 이르게
- **C** 적지 않는다
- **D** 현재 시각

<details><summary>정답</summary>

**B** — 늦으면 코인을 놓친다

복구 지갑의 생성 시점을 적을 때 안전한 쪽은 B, 조금 이르게입니다. 늦게 적으면 그 전에 받은 코인을 놓치고, 이르게 적으면 재스캔이 조금 길어질 뿐입니다. 적지 않으면 전체 재스캔이 필요하고, 현재 시각은 너무 늦은 값입니다.

</details>

## Q3. Bitcoin Core 지갑을 백업하는 올바른 방법은?

- **A** 12단어 받아 적기
- **B** backupwallet 또는 개인 디스크립터
- **C** 스크린샷
- **D** 주소 목록 저장

<details><summary>정답</summary>

**B** — Core는 BIP39 미지원

Bitcoin Core 지갑을 백업하는 올바른 방법은 B, backupwallet 또는 개인 디스크립터입니다. Core는 BIP39를 지원하지 않으니 12단어는 해당하지 않고, 스크린샷이나 주소 목록으로는 개인키를 되살릴 수 없습니다.

</details>
